dependencies and build tools are fetched separately; lockfile checksums do
not substitute for their license terms.

This is not a transitive dependency, compiler, linker or native-runtime notice
set for a binary or vendored release. Such a distribution needs its actual
applicable texts, notices, corresponding source and source-availability wording
reviewed for the inventory it conveys. No rights or aggregate release-license
conclusion follows from this index alone.
