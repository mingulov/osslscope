# osslscope ID map (registry v1)

Operation, function, and API entry-point ids from the frozen
registries (`src/kinds.rs`, P1-0 freeze). Sources: `OSSL_OP_*` /
`OSSL_FUNC_*` from `openssl/core_dispatch.h` (3.0.22, 3.5.8,
3.6.0, 4.0.2); `ENGINE_*` from `openssl/engine.h` (3.x; 4.x
ships deprecation stubs only); fetch/SKEY from `evp.h`,
`kdf.h`, `encoder.h`, `decoder.h`.

Labels are NON-AUTHORITATIVE display aids for human output.
Identity decisions use exact (object, digest) pairs, never
these names. Unknown ids stay numeric and explicit in human
output (`OPnn`, `FUNCnn`); JSON always carries exact numbers.

Do not hand-edit: regenerate with
`OSSL_REGENERATE_ID_MAP=1 cargo test --test id_map
regenerate_id_map`, review the diff, then commit.
